# COMP9517 iNaturalist report - Overleaf package

Upload this entire folder to a new blank Overleaf project and set `main.tex` as
the main document. It is self-contained: the official CVPR style file,
bibliography, and all figure assets used by the report are included locally.

The already-rendered submission PDF is included only as a visual reference;
Overleaf builds the report from `main.tex` and `references.bib`.

Before final submission, add every group member to the `\author{...}` block in
`main.tex` if the report is to list the full group.
